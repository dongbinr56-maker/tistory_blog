분산 인프라 연결을 위한 오픈소스 메시 네트워킹 플랫폼 Tunnet

물리적으로 격리된 장치들을 중앙 서버 없이 직접 연결하여 안전한 사설 네트워크를 구성할 수 있게 돕는 오픈소스 메시 네트워킹 플랫폼 Tunnet이 공개되었습니다.

이 플랫폼은 서로 다른 장소에 있는 컴퓨터들을 마치 하나의 방에 있는 것처럼 안전하게 연결해 주는 가상 네트워크 도구입니다. 중앙 서버를 거치지 않고 컴퓨터끼리 직접 데이터를 주고받을 수 있어 보안성이 높습니다.

여러 클라우드 리전이나 로컬 온프레미스 서버에 분산된 AI 연산 장비들을 복잡한 방화벽 규칙 변경 없이 안전하게 묶어 단일 사설 네트워크로 관리할 수 있습니다.

메시 네트워크는 단일 장애점이 없다는 구조적 장점이 있으나, 노드 수가 늘어날수록 피어 간 연결 상태를 유지하기 위한 오버헤드가 증가합니다. 대용량 텐서 데이터를 실시간으로 전송해야 하는 분산 학습 환경에서는 라우팅 지연 시간과 물리적 대역폭 한계를 사전에 면밀히 측정하고 도입 여부를 결정해야 합니다.

서로 다른 네트워크 환경에 있는 기기 두 대를 준비하여 직접 패킷 전송 지연 시간(Ping)을 측정해 보기를 권장합니다.
