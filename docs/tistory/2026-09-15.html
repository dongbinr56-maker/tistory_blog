아이폰이나 맥북에 내장된 기본 음성 비서의 두뇌 역할을 애플 자체 기술 대신 사용자가 원하는 다른 회사의 인공지능으로 갈아 끼울 수 있게 된다는 의미입니다. 기기 내부의 깊숙한 명령 처리 계통을 외부 모델에 열어주는 구조입니다.

애플이 자사 생태계의 관문인 시리를 개방하는 결정은 파격적이지만, 온디바이스의 민감한 개인 정보가 외부 API로 전송되는 과정에서 발생할 데이터 유출 위험을 어떻게 통제할지가 관건입니다. 샌드박스 수준의 엄격한 보안 필터링이 전제되지 않는다면 기업용 단말 환경에서의 도입은 극히 제한될 것이므로, 향후 공개될 데이터 암호화 및 전송 규격을 면밀히 추적해야 합니다.

애플의 차세대 운영체제 개발자 가이드라인이 업데이트되는 대로 모델 위임 시 발생하는 데이터 흐름도와 프라이버시 정책을 분석합니다.
