외부 네트워크 연결이 불가능한 폐쇄망 환경이나 데이터 유출 우려가 있는 엔터프라이즈 환경에서 비용 지출 없이 독립적인 이미지 생성 파이프라인을 구축하는 데 유용합니다.

사용 중인 GPU의 가용 메모리를 측정하고, 적절한 양자화 수준의 GGUF 파일을 내려받아 토큰당 생성 속도를 비교해 봅니다.

실제 프로젝트에서 사용하는 복잡한 표나 한글 폰트가 포함된 템플릿을 pdfcn에 적용하여 레이아웃 깨짐 현상이 발생하는지 확인해 봅니다.
